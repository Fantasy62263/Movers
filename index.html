📌 BẢNG THẦN CHÚ NGỮ PHÁP
1. So Sánh Hơn (Ngắn) S + be + adj-ER + THAN
taller than, faster than
2. So Sánh Nhất (Ngắn) S + be + THE + adj-EST
the tallest, the fastest
3. Quy Tắc Chính Tả Đuôi -y: happy → happier / happiest
Gấp đôi: hot → hotter, big → biggest
4. Bất Quy Tắc & Dài good → better → the best
bad → worse → the worst
more beautiful than / the most...
